# nodaysidle for Linux v0.3.0

The Qt 6 rewrite: a native Omarchy browser on QtWebEngine (Chromium), pure Wayland, now with saved passwords, import from other browsers and an Arch package for the launcher.

Both need `qt6-base`, `qt6-declarative`, `qt6-webengine`, `qt6-wayland`, `openssl` and `libsecret`, and a Secret Service keyring such as `gnome-keyring` for saved passwords.

```sh
sha256sum -c --ignore-missing SHA256SUMS
sudo pacman -U nodaysidle-browser-0.3.0-1-x86_64.pkg.tar.zst
```

## New

- **Passwords.** The browser offers to save, update or never save a login after you sign in, and fills it in when you return, including two-step sign-ins. Logins are encrypted with AES-256-GCM; the key is held in your keyring, never on disk. `Ctrl+Shift+K` opens the list.
- **Import.** Bookmarks and history from Chrome, Chromium, Brave, Edge, Vivaldi, Opera, Firefox, Zen, LibreWolf, Floorp and Waterfox; passwords from the Chromium family; any passwords CSV.
- **History** panel (`Ctrl+H`) and omnibox suggestions from history and bookmarks.
- **Ad and tracker blocker**, built in.
- **Print to PDF** (`Ctrl+P`), site icons on tabs, find with match count, downloads, popups for sign-in flows.
- **Permission bar** that never stores a Deny.
- **Arch package** (`bin/install`) so the app appears in the Omarchy launcher.

## Changed

- The start page is just "nodaysidle" and the search pill.
- The bookmarks bar starts empty; the four seeded bookmarks are removed.
- Toolbar icons are drawn on one grid so they align.

## Fixed

- Pages that came back from a form POST were fetched again with GET, so a wrong-password page turned into the home page.
- Google sign-in ("This browser or app may not be secure") and sessions persisting across restarts.
