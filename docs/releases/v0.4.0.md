# nodaysidle for Linux v0.4.0

An assistant that reads the page you are on, now on DeepSeek, and a full security and usability pass: the renderer sandbox is back on, saved passwords fill only after a click, your tabs come back after a restart, and every control can be reached from the keyboard.

## New

- **Ask this page** (`Ctrl+Shift+E`). Ask questions about the page you are reading, or press Summarize or Key points. Answers stream from DeepSeek `deepseek-flash`; follow-up questions keep the conversation, and a new page starts a fresh one. Set `DEEPSEEK_API_KEY` in your environment or fish config. Nothing is sent until you ask; then the page title, URL, the first 50,000 characters of its text and the conversation go to `api.deepseek.com`.
- **Your tabs come back** after a restart, and `Ctrl+Q` asks first when more than three tabs are open.
- **Downloads ask first.** A shelf shows where the file comes from and its size; nothing is written until you press Save.
- **Undo** for Clear all history and Delete Bookmark; deleting a password needs a second click.
- **A crashed page says so**, with the reason and a Reload button, instead of going blank.
- **Certificate errors** show a bar naming the host and the reason.
- **Popup windows** show a read-only address line, so you can see which site opened them.

## Changed

- **Saved passwords fill only after you click** the field, never by themselves, and never over plain `http` except on your own machine.
- **Keyboard and screen readers.** Every control has a name and a role, the toolbar can be walked with Tab, click targets are at least 24 px, and the history and password lists work from the keyboard. `Ctrl+T` puts the cursor in the address bar, and leaving the address bar hands the keyboard back to the page.
- **Theme.** Reads every key Omarchy themes use, follows the theme's light or dark mode, and adjusts text colors to WCAG AA contrast; checked against all 24 Omarchy themes.
- **Lighter in the background.** Hidden tabs are frozen (unless they are playing sound), and the Hyprland corner radius is no longer polled every second.
- **Faster start.** Imports run in the background, and the window opens before the keyring is unlocked.
- **Scam check** (TypeSafe) says up front where the text goes, shows when it is working, gives up after 30 s, and explains errors in plain words. The Anthropic assistant from earlier builds is removed; Ask this page replaces it.

## Fixed

- The Chromium renderer sandbox is enabled again.
- Popups that did not come from a click or a key press are blocked.
- A permission prompt stays with the tab that asked for it.
- The password vault refuses to start instead of using a weak key if the system's random source fails.
- History and bookmarks are written atomically, so a crash cannot leave them half written; bookmarks are stored with mode 0600.
- A page opened from a local file can no longer read other local files.
- API keys in the fish config are found in every `set` form, including escaped values.
